# Support

This project is shared as a reference sample and is **not actively maintained**. There is no guaranteed response time; support is best-effort via [GitHub Issues](../../issues).

- Start with the [README](README.md) for architecture, fixture expectations, local checks, configuration, and deployment.
- For fixed-template WfP behavior and CLI usage, read the [Emdash example](examples/emdash-wfp/README.md).
- Report reproducible defects with the [bug report template](.github/ISSUE_TEMPLATE/bug_report.md). Describe the fixture, runtime versions, expected target, actual result, and a non-sensitive log excerpt.
- Suggest a bounded improvement with the [feature request template](.github/ISSUE_TEMPLATE/feature_request.md).
- Report suspected vulnerabilities through [private vulnerability reporting](SECURITY.md), not a public issue.

For product limits, billing, and platform support, consult the [Cloudflare Developer Platform documentation](https://developers.cloudflare.com/workers/) and your normal Cloudflare support channel. This sample does not provide support for individual account configurations or production workload guarantees.
