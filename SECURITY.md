# Security policy

This repository is a public reference sample; updates and responses are best-effort, with no guaranteed response or fix time.

## Supported versions

| Version                                       | Support                      |
| --------------------------------------------- | ---------------------------- |
| `main`                                        | Best-effort security fixes   |
| Older commits, forks, and private deployments | No supported release channel |

There are no versioned security releases yet. Keep third-party dependencies, the pinned Sandbox preview image, Wrangler, and your own deployment current.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/Gryczka/cloudflare-nextjs-compatibility-demo/security/advisories/new) to send a report privately to the maintainers. Include a minimal reproduction, affected commit, expected impact, and any suggested mitigation. Do **not** post exploit details or credentials in a public issue. The reporting link is available once the public repository has private vulnerability reporting enabled.

We will review reports and coordinate a fix and disclosure where appropriate, on a best-effort basis. Please allow time to investigate before disclosing details publicly. For ordinary bugs and questions, use [GitHub Issues](../../issues).
